# Resume Workflow

A version-controlled system for maintaining a verified master resume and creating tailored resumes for different job opportunities.

## Project Purpose

I created this project to solve a problem I had with maintaining multiple versions of my resume. Over time, I accumulated different resume files containing different sets of experience, skills, and project information, which made it difficult to know which version was current.

The goal of this project is to maintain one verified resume as a source of truth and use Git to track how it changes over time. Instead of creating a new file for every revision, Git provides a version history that shows what changed, when it changed, and why.

From this source resume, I can create tailored resumes for specific job opportunities while keeping the underlying career information consistent.

## Privacy and Redaction

The resume stored in this public repository is a redacted version of my master resume. It contains the professional information needed to build and maintain my resume while excluding private contact information such as my personal email address, phone number, and street address.

My complete master resume is maintained separately and is not stored in this repository.

This approach allows me to use Git and GitHub for version control and portfolio documentation without publishing unnecessary personal information.

## Workflow

This repository can be maintained from macOS and iOS using Git and Working Copy.
